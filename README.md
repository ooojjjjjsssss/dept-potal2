# 유진그룹 채용 부서포털

단일 HTML 페이지로 만든 채용 안내 포털입니다. 별도 설치나 서버 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

## 폴더 구성

```
├─ index.html                  포털 메인 페이지 (v2)
├─ files/                      내려받기용 자료
│  ├─ culture-introduction.pdf   인재상·조직문화 소개서
│  └─ job-posting-2026-h1.pdf    2026년 상반기 채용공고
├─ 이전버전/
│  └─ portal-v2.html             index.html 변경 전 원본 사본
└─ README.md
```

## 사용법

1. `index.html`을 더블클릭하거나 브라우저 창에 끌어다 놓아 엽니다.
2. 화면 상단의 고정 메뉴로 섹션을 이동합니다. 메뉴를 누르면 해당 섹션으로 스크롤되고, 스크롤 위치에 따라 현재 메뉴가 강조됩니다.

| 메뉴 | 내용 |
| --- | --- |
| 홈 | 포털 소개와 주요 수치, 채용 공고·채용 절차 바로가기 |
| 채용 절차 | 4단계 전형 흐름 안내 |
| 직무 소개 | 모집 직무 3종의 요약과 상세 요건 |
| FAQ | 자주 묻는 질문 (항목을 누르면 답변이 펼쳐짐) |
| 자료실 | `files/` 폴더의 PDF 목록(파일명·설명·용량)과 다운로드 버튼 |

## 내용 수정하기

- 텍스트나 문구는 `index.html`을 메모장·VS Code 등으로 열어 해당 부분을 직접 고칩니다.
- 색상과 글꼴은 파일 상단 `<style>`의 `:root` 변수(`--bg`, `--ink`, `--blue` 등)에서 한 번에 바꿀 수 있습니다.
- 자료를 추가하려면 `files/`에 영문 파일명으로 넣고, 자료실의 `file-item` 블록을 복사해 `href="files/파일명.pdf"`, `download="저장될 한글 이름.pdf"`, 설명, 용량을 바꿉니다.

## 파일 관리 규칙

- 파일명은 한글·공백 없이 영문 소문자와 하이픈(`-`)만 사용합니다. (예: `job-posting-2026-h1.pdf`)
- PDF·Word 등 내려받기용 문서는 `files/` 폴더에 둡니다.
- 큰 수정을 하기 전에 현재 `index.html`을 `이전버전/` 폴더에 복사해 보관합니다.
